# 第二章 · 生活区物件与对白锚点清单（只列不改）

> 问题：对白里说的东西，玩家在生活区找不到对应的实物。
> 结论三句话：**① 台词提了 13 样东西，场景里只做出了 3 样半；② 剩下的不是「没做」，而是「没有能指认的名字」，做出来也没法被台词点到；③ 生活区目前是「几个 NPC 站在空地上」，缺的是让这几句话成立的那几件道具和那几段距离。**

依据：`scripts/chapter2/ch02_lines.gd`（当前 22 个函数）、`scripts/chapter2/ch02_workshop_hub.gd`（生活区装配，1630 行）、`scenes/chapter2/living/camp.tscn`、`cottage.tscn`、`garden.tscn`、`scenes/chapter2/deck/hub_deck.tscn`。

生活区实测坐标：椭圆台地半径 26×21、中心 `(2,0,0)`；陶陶 `(2,0,4)` 面朝南；餐车 `(5.2,0,3.2)` 转 -0.55；旧料理机械 `(9,0,2.6)`；厨台 `(-8.4,0.4,4.4)`，四份食材 z=3.7；地毯 `(3.2,0.605,4)`；居民四人 —— `resident_pair_a (-10.5,0,10.8)`、`resident_pipe (-13.5,0,-1)`、`resident_queue (10.8,0,0.5)`、`resident_tent (-12,0,-10.5)`；中央管道 y=5、z=-1、x 从 -13 到 15，垂管落在 x=-12 与 x=14。

## 一、结构性问题（这三条不解决，做多少道具都白搭）

### S1　生活区三块预制体全是匿名节点

`camp.tscn` 的节点叫 `_MeshInstance3D_96` … `_MeshInstance3D_115`，`cottage.tscn` 叫 `_MeshInstance3D_117` … `_MeshInstance3D_150`，`garden.tscn` 叫 `_MeshInstance3D_175` … `_MeshInstance3D_215`。全场景只有碰撞体有名字（`Col_Crate_W`、`Col_Barrel_E`）。

后果：没法写「去看看那只碗」「那口箱子有校印」——**没有可寻址的东西**。现在能交互的只有 NPC（靠 `_make_npc` 的 key）和厨台/食材（靠 `Ch02Ingredient` 脚本）。

改法：给要用的物件定名，`Prop_` 前缀 + 语义名，碰撞体同名 + `_Col`。建议最小集：`Prop_Cart`、`Prop_CartLid`、`Prop_PotLid`、`Prop_LunchBox`、`Prop_Crate_Stamped`、`Prop_Bell`、`Prop_LoadingDock`、`Prop_Bench`、`Prop_Tube`、`Prop_Lamp`。camp/cottage 里的火盆、床铺、货箱、木桶同理。

### S2　生活区没有「查看」这一层交互

现在能按 F 的只有：陶陶、4 个居民、旧料理机械、厨台、4 份食材。**所有摆件都是纯装饰**，玩家把准星压过去，什么都不会出现。

改法：加一个十几行的通用组件 `scripts/chapter2/ch02_prop.gd`（`class_name Ch02Prop extends StaticBody3D`），字段 `prompt: String`（默认「按 [F] 看看」）、`examine: Array`（复用 `Ch02Lines` 的 `{who,text}` 格式，直接喂 `ch02_dialogue`）、`flag_key: String`（看过记一次，避免重复播放）、`interact_range`。挂上去就等于「这东西能看，还能说一句话」。

这是本清单里性价比最高的一项：S2 做完，S1 的命名才有意义，后面每一件道具的收益立刻翻倍。

### S3　台词里出现、场景里完全不存在的 13 样东西

按出现顺序：

| # | 台词（`ch02_lines.gd`） | 场景现状 | 玩家会怎么想 |
|---|---|---|---|
| 1 | 「餐车停在坡口，**车盖掀着**」（`:17`） | 餐车顶是一块 1.82×1.02 的平金属板，没有盖子，也没掀 | 「哪来的车盖？」 |
| 2 | 「**半扇旧烤炉门**当桌面」（`:17`） | 没有烤炉门 | 读成普通桌子 |
| 3 | 「上面摊着一张**揉皱的地图**」（`:17`） | 车顶空着；地图只存在于 UI 里（按 M 才出现） | 台词说摊着，眼前什么都没有 |
| 4 | 「她从车斗里摸出一只**带盖的饭盒**」（`:23`） | 没有饭盒；拿完之后背包里也没有 | 这句话像凭空发生 |
| 5 | 「**锅盖**呢？」「路上弄丢了」（`:19-21`） | 玩家手上是一口平底锅，**本来就没有盖**，也没有「丢了」的视觉线索 | 玩不懂这个梗 |
| 6 | 「岩壁高处响了**一声卸货铃**」（`:27`） | 无铃、无声源、无动画 | 只听到一句提示条文字 |
| 7 | 「撞在**卸货台**上」（`:29`） | 生活区没有卸货台（运输站在六十米外） | 撞车发生在看不见的地方 |
| 8 | 「把**站台的路和一户人家的楼梯**一起罩住」（`:29`） | 楼梯在台地北口（通用大阶梯），没有「一户人家」的楼梯 | 找不到那户人家 |
| 9 | 「陶陶，**我妈下不来**！」（`:30`，小孩） | **没有小孩 NPC**，也没有他妈 | 一个不存在的人喊话 |
| 10 | 「我把**伤员**和锅先挪开」（`:32`） | 没有伤员 | 说的东西都不在场 |
| 11 | 「**墙上的通话管**响了」（`:238`，Boss 战前） | 全项目没有通话管模型/交互 | 声音凭空出现 |
| 12 | 「你在**运输箱上看到的校印**」（`:39`） | 生活区有货箱（`camp.tscn` 的 Crate），但没有校印、也不能看 | 玩家根本没看过校印 |
| 13 | 「（战后）还没找到**另一只手套**」（`:182`） | 没有那个孩子，也没有手套 | 一句无法验证的好意 |

外加两件「有，但指不到」的：`检修灯`（`rift_check` 由陶陶递给玩家，生活区里从来没出现过这盏灯）；`长凳`（`taotao_rested` 说「在长凳边坐下」，但长凳在上一轮被删了——`ch02_workshop_hub.gd:462` 注释写着「不再摆长凳和货箱」，现在只有 `ch02_terrace_d.gd:142` 的长椅，在另一层台地上）。

### S4　台词描述的物件，和模型不是同一个东西

- **锅**：台词「你这口锅，盖子能盖住半张桌子」（`:21`），玩家手里是 `cave_player.gd:515` 的**平底锅**（锅 + 手柄，参照第一章），尺寸比手掌大不了多少。台词把它当成一口大锅。
- **灶**：台词「她把那口汤从灶上端下来。火灭了」（`:31`）。生活区真正的灶在 `(-8.4,0.4,4.4)` 的厨台，离餐车 13.6 米；餐车上只有一只 0.32 米高的量杯状小锅。玩家不知道「灶」指哪一个。
- **管子**：`resident_pipe` 说「这根管子就烫」（`:67`），他站 `(-13.5,0,-1)`，头顶那根管道在 y=5、z=-1，最近的垂管在 x=-12。**他离管子 1.5 米，没碰着，也没有烫的视觉（没有蒸汽、没有灼热色）**。

## 二、逐场对白的「指认缺口」

### 初见（`taotao_first`，16 行）

现在玩家站到餐车前，看到的是：一辆红色围板 + 金属台面 + 一只小锅 + 两只碗 + 一把伞的车。台词要求他看到一个**掀开的车盖、一扇旧烤炉门、上面摊着地图、旁边放着一只带盖饭盒**。

缺的连续性：
1. 车盖不存在 → 「掀着」这句话没有落点；
2. 地图不在车上 → 按 M 之前，玩家不知道地图长什么样，也不知道它从哪来；
3. 饭盒不存在 → `fx:"quest"` 那一句是纯文字；
4. 锅盖这句梗没有可看的证据（锅本来没盖、也没有「本该有盖」的对比物）。

建议（只列，不改）：
- 车盖做成**合页掀板**，掀到 100° 立在车后；掀板内侧就是地图（`ch02_map_view` 的纹理可以直接烘一张 512 的贴图上去）；
- 掀板上再压一枚**旧烤炉门把手**，坐实「半扇旧烤炉门当桌面」；
- 饭盒做成 0.22×0.14×0.12 的铝盒（带扣），放在地图边缘；按 F 拾取后进 `food_inventory`，并在玩家左手挂一个 3cm 的小方块当持有物；
- 锅盖：在餐车侧面挂 3 个**对不上号的锅盖**（不同尺寸、都小一圈），玩家一看就懂「盖不住」；陶陶那句「盖子能盖住半张桌子」改成对这种荒谬的回应。

### 撞车（同一段后半）

台词把撞车写成**眼前的事件**（白汽罩住站台的路和一户人家的楼梯），但站台在六十米外，楼梯在台地北口。

三种改法（任选）：
- **A 搬到生活区**：在东侧墙根 x≈20、z≈-8 处做一段 4 米长的**卸货台 + 吊臂 + 铃**，货车从墙上的斜坡滑下来撞在台子上，白汽挡住东侧主通道（这里就是去运输站的路），并挡住北口一户人家的楼梯。玩家在餐车边一回头就能看见。
- **B 改成听见**：旁白只写声音（铃、金属撞击、汽），把「我过去看看」交给陶陶的下一句；白汽的遮挡改到运输站那边由场景表现。
- **C 拆成两拍**：铃响在生活区，撞车等玩家走到运输站才看见（但任务卡要先给出目的地）。

推荐 A —— 它顺手把 #6 卸货铃、#7 卸货台、#8 楼梯三个缺口一次填掉，且给了「去运输站的路被挡住」这个玩家本来就要理解的信息。

### 伤亡与小孩

「我妈下不来」+「伤员」需要两个 NPC（小孩 + 一个被架住的老人）和一处**楼梯**。现在台地北口有通用大阶梯，但没有「某户人家」的门。

建议：把北口西侧那栋 cottage（`cottage.tscn` 烘死了位置）旁边加一段 6 级**户内梯**+ 一扇开着的门，小孩站梯口、他妈在梯上；伤员两人躺在餐车东侧（可用 `ch02_npc` 的 `kind` 加一个 `"wounded"` 变体：坐/躺姿势 + 绷带）。

### 居民四人（`resident`，`:64-90`）

| NPC | 台词 | 现在站在 | 台词成立吗 |
|---|---|---|---|
| `resident_pipe` | 管子烫 / 离远了又冷 | 垂管旁 1.5 米 | 勉强。缺蒸汽与灼热色 |
| `resident_pair_a` | 「陶陶说今天有汤」「我排在后面」 | 西南空地 | **不成立**：餐车边没有人排队 |
| `resident_queue` | 「那台机器以前一次揉二十人份面」 | 离机器 2.3 米 | 成立，但机器身上看不出「揉面」的部件 |
| `resident_tent` | 「栈道上面那顶旧帐篷」 | 台地西侧 | **不成立**：帐篷在台上、四十米外，看不见 |

建议：
- 在餐车南侧摆**排队区**：一条 3.2 米的矮木栏 + 地上 4 个脚印贴片/4 只空碗，两三个居民站在里面（`resident_pair_a` 挪到队尾）；
- `resident_queue` 挪到机器正前 1.2 米，机器加一个**面盆 + 揉面臂**（两根圆柱）让他指着说话；
- `resident_tent` 的台词改成本地的东西（比如「上面那户的灯又忘了关」），或者把他挪到栈道口、让他变成「往上看」的人。

### 旧料理机械（`machine`，`:56-58`）

三句话分别点了**碗、夹钳、收音机**。现在：`robot.glb` 换掉程序化外壳，胸前只有一个 0.28×0.2×0.16 的金属块，碗/夹钳/收音机都不存在。

建议：托架上放一只**缺口的碗**（`CylinderMesh` 顶部少一格，或用两段圆柱拼），夹钳做成从他肩侧伸出来、**张到一半卡住**的两片金属（这句是全章最好的一个意象，值得做实），收音机做成脚边一只 0.3 米的小箱子 + 一张会闪的自发光面片 + 环境音里的电流声。

### 支线与收尾

- `taotao_stuck` / `taotao_rested` 提到**主炉接口、扳手、长凳**。接口与扳手在 `ch02_workshop_hub.gd:1384` 的 `_build_junction()` 里有，长凳没了（见 S3 末尾）。建议把 `ch02_terrace_d.gd:142` 的长椅样式复用一份到接口旁。
- `taotao_ending` 的两条线：小灶线要「水开了」，锅线要「还有几户等热饭」——**两个都要能看见的灶台与排队的人**（同上）。「另一只手套」需要那个孩子在场。

## 三、空间与动线问题

1. **中央是空的**：台地 52×42，可玩家从南口走到餐车这 16 米里，除了地毯和两盆植物什么都没有。台词却在这里讲「营地」「住户」「伤员」。建议在南口到餐车之间放：一排水桶、一辆坏掉的板车、两条晾着的布。
2. **厨台离餐车 13.6 米**，中间隔着一整片空地。台词的逻辑是「陶陶在餐车分饭、厨台在做饭」，两者应该挨着（≤6 米），否则玩家以为厨台是另一个地方的东西。
3. **四人分散在四个角落**，互相之间没有视线关系。建议把他们收到台地南半部（餐车、机器、管道、帐篷口四个点位），北半部留给住户与楼梯。
4. **东侧主通道没有任何提示**：玩家不知道往东是运输站。加一个**路牌 + 地面的车辙**，与地图上的「东」呼应。

## 五、如果只做五件事

1. **S2 的通用 `Ch02Prop`**（一次投入，之后每件道具都变便宜）。
2. **车盖 + 地图 + 饭盒 + 三个锅盖**（初见这一段是玩家对「这个世界有生活感」的第一判断）。
3. **卸货台 + 铃 + 小孩 + 楼梯**（把撞车从「听见」变成「看见」）。
4. **排队区 + 居民重新落位**（四个人一旦互相有关系，生活区立刻不再像空地）。
5. **机器身上的碗/夹钳/收音机**（三句话三个实物，是全场最像「有人住过」的一处）。
