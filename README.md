## 推荐开发顺序

### 第一阶段 核心手感

为现有奶龙模型补充骨骼与待机、跑步、挥锅、翻滚动画，再完成受击反馈、镜头震动和一个普通敌人的完整行为。先确保移动、攻击、翻滚有清晰手感。

### 第二阶段 配方闭环

把 `recipe_system.gd` 中的配方定义迁移为自定义 Resource，补齐料理槽、营火锅调整界面和 10 个正式配方。技能最好各自做成独立 PackedScene，并统一伤害与状态接口。

### 第三阶段 关卡与敌人

加入 4 种普通敌人、1 种精英敌人和波次数据。再实现油渍点燃、冰面滑行、餐桌挡弹道等场景互动。

### 第四阶段 Boss 与完整流程

将当前放大版占位敌人替换为暴食烤炉 Boss，拆成吸入、喷火、焦炭和旋转餐具四种攻击。补齐教学、暂停、失败、胜利和重新开始流程。

### 第五阶段 美术与展示

最后处理 Toon Shader、描边、粒子、音效、食谱卡片 UI、性能和课堂演示材料。不要在核心构筑尚未好玩之前投入大量模型制作。

## 扩展建议

首版只维护人工确认的 10 个配方，其他组合使用通用属性叠加。所有食材与技能尽量数据驱动，避免把组合逻辑散落在玩家脚本里。正式制作时可以新增 `resources/ingredients`、`resources/recipes` 和 `scenes/skills` 三个目录，把当前字典逐步替换成 `.tres` 资源。
