# 百味法师第三版

保留第二版的瘦高身形、年轻尖脸、尖下巴和尖鼻子。衣服增加真实开口的破洞、焦边、零散布线和撕裂下摆；帽身改为多层错落堆叠的布褶，带凹陷折痕和搭接布片。

已更新项目 A:/Monste/MonsterDone_Godot。双击项目根目录 Preview_Culinary_Wizard.cmd 可以查看新版。左键拖动旋转，滚轮缩放，空格自动旋转，R 重置，Esc 退出。

culinary_wizard.blend 是可编辑 Blender 源文件，culinary_wizard.glb 是游戏模型，wizard_preview.png 是全身渲染，wizard_hat.png 是帽子特写，godot_preview.png 是实际 Godot 显示截图。

这一版仍是造型原型，尚未绑定骨骼或加入战斗动画。上一版模型和 Blender 文件保存在项目 backups 文件夹中。
